## Reviewer Note

Nobs' current grey-blue foreground was accepted, but a vibrant source foreground would be preferable if one satisfies the existing contrast requirements. This is a foreground-ranking question, not justification for relaxing foreground-to-surface contrast.

## Decision

The next experiment may test whether fully accessible chromatic foregrounds should receive more identity weight.
